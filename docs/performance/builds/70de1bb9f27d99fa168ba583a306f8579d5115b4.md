2. Dungeons settings > Game Graphics: Sharp / Efficient, selected output 2128 × 1600, 60 FPS, Balanced, Driver Default. MetalFX Spatial ON, MetalFX Input Budget **80%** (same tested choice). Mark only manual interruptions as excluded; real gameplay hitches stay included. Note the action causing any issue.

Stop Test > Export report and JSON > Share exported files: save **report.md + diagnostics.json** as session A (MetalFX ON). No need to resend old logs. Startup attempt log only if activation fails.

Inventory target/area groups and direct clock markers should be available; absence/loss is diagnostic, never a reason to declare scene resolution or quality proven. Let the device return near its starting warmth; keep brightness/scene/other launch settings unchanged. Leave Render Target Inventory and GPU Sampling ON for this short paired diagnostic.
